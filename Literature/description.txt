# Предметная область «Литература»

Программа представляет собой консольный каталог литературы.

Основные классы предметной области: Author, Genre, Book и Hall. Дополнительно используются классы Publisher, BookCollection, Library и CatalogService.

Класс Author хранит сведения об авторе. Класс Genre описывает жанры литературы и является абстрактным. Его наследники FictionGenre и EducationalGenre представляют художественные и учебные жанры. Класс Book хранит сведения о произведении, его авторе, жанре, издательстве и зале. Класс Hall описывает зал, в котором размещена литература.

Программа позволяет просматривать каталог, искать книги по названию, автору или жанру, фильтровать книги по жанру и залу, просматривать список авторов и добавлять новые книги.

При запуске создаётся начальный каталог из 40 литературных наименований.

В проекте применяются наследование, инкапсуляция, полиморфизм и интерфейс IBookSearch. Класс Library управляет данными каталога, BookCollection хранит книги, а CatalogService выполняет поиск и фильтрацию.
